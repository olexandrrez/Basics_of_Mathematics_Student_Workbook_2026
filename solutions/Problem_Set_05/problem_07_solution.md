# Problem 7: Intersection of an Ellipse and a Line

## Problem

Find the intersection points of the ellipse and line
$$\frac{x^2}{4}+y^2=1,\qquad y=\frac{x}{2}.$$

## Worked Solution

Substitute the line equation into the ellipse. Since $y=x/2$, we have $y^2=x^2/4$, so
$$\frac{x^2}{4}+\frac{x^2}{4}=1\quad\Longrightarrow\quad\frac{x^2}{2}=1\quad\Longrightarrow\quad x^2=2.$$
Thus $x=\pm\sqrt2$. Using $y=x/2$, the matching $y$-coordinates have the same signs:
$$\boxed{\left(\sqrt2,\frac{\sqrt2}{2}\right),\quad\left(-\sqrt2,-\frac{\sqrt2}{2}\right)}.$$

**Check.** At either point $y^2=x^2/4=1/2$, so $x^2/4+y^2=1/2+1/2=1$, and both also satisfy $y=x/2$.
