# Problem 6: Intersection of a Line and a Plane

## Problem

Find the intersection of the line
$$ (x,y,z)=(0,1,0)+t(1,-1,2)$$
with the plane $x+y+z=5$.

## Worked Solution

Read the coordinates from the parametric line:
$$x=t,\qquad y=1-t,\qquad z=2t.$$
Substitute into the plane equation:
$$t+(1-t)+2t=5\quad\Longrightarrow\quad1+2t=5\quad\Longrightarrow\quad t=2.$$
Substitute this parameter into the line to get
$$ (x,y,z)=(2,-1,4).$$

**Answer:** $\boxed{(2,-1,4)}$.

**Check.** $2+(-1)+4=5$, so the point lies on the plane; it is also the line's point at $t=2$.
