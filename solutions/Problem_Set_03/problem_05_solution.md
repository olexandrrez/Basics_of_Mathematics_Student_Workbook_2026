# Problem 5: Angle Between Two Vectors

## Problem

Calculate the angle between $u=(1,1,0)$ and $v=(1,0,1)$. State whether the vectors are perpendicular.

## Worked Solution

Use the dot-product formula $u\cdot v=\|u\|\|v\|\cos\theta$. Here
$$u\cdot v=1,\qquad \|u\|=\sqrt2,\qquad \|v\|=\sqrt2.$$
Therefore
$$\cos\theta=\frac{1}{\sqrt2\sqrt2}=\frac12,$$
so the angle between the vectors is
$$\boxed{\theta=60^\circ=\frac\pi3}.$$

The vectors are not perpendicular: perpendicular vectors have dot product zero, while this dot product is $1$.

**Check.** Since $\cos60^\circ=1/2$, the angle agrees with the computed cosine.
