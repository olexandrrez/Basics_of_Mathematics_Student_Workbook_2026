# Problem 10: Three Concurrent Lines

## Problem

Find the value of $k$ for which the three lines $x+y=4$, $2x-y=2$, and $kx+y=6$ pass through one common point. Give that point.

## Worked Solution

First find the intersection of the first two lines. Adding their equations eliminates $y$:
$$x+y+2x-y=4+2\quad\Longrightarrow\quad3x=6\quad\Longrightarrow\quad x=2.$$
Then $y=4-x=2$. Any common point must therefore be $(2,2)$. Substitute this point into the third line:
$$k(2)+2=6\quad\Longrightarrow\quad2k=4\quad\Longrightarrow\quad\boxed{k=2}.$$

**Answer:** $\boxed{k=2}$ and the common point is $\boxed{(2,2)}$.

**Check.** The point satisfies the first two equations, and with $k=2$ it also satisfies $2(2)+2=6$.
